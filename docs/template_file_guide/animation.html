Animation

Animations are created using <animation>
An animation can either be a tween, spring, bezier or oscillator

example of a animation

<animation>
	| ID : "spring_0"
	| Type : "Spring"
	| Instance : node_1
	| Props : {
		["Goal"] : <cframe>([<vec3>([0,0,0]),<vec3>([1,0,0])]),
		["Property"] : "Offset",
		["Damping"] : 0.5,
		["Frequency"] : 1,
		["Response"] : -1,
		["Time"] : 1
	}
</animation>

this matches how you'd use Cinnamon.Animation.Animate()

Animations on compilation are disabled, so to play them you'd have to set their enabled property true after compilation

local Import = Cinnamon.Compile(source,reference)

Import["spring_0"].Enabled = true

Batch animations

Batch animations allow you to animate multiple objects at the same time
Like how you'd use Cinnamon.Animation.BatchAnimation()

batch animations are created using <batchanimation>

<batchanimation>
	| ID : "batch"
	| Instances : [node_0,node_1]
	| Props : {
		["EasingStyle"] : "Sine",
		["EasingDirection"] : "In"
	}
	| GroupData : {
		["Goal"] = [<cframe>([0,0,5]),<cframe>([0,5,10])]
	}
	| Type : "Tween"
</batchanimation>

Batch Animations are also disabled on compilation, so to play them you'd have to call BatchAnimation.SetEnabled()

local Import = Cinnamon.Compile(source,reference)

Import["batch"].SetEnabled(true)

Timelines

Timelines allow for multiple animations to be grouped together

a new entry is represented as ```

| [Duration] -> {}

a map is used to describe the changes made to the animation's properties before doing the next animation
Timeline entries are played from top to bottom, using the attached animation as the first animation played

<animation>
	| ID : "tween_0"
	| Type : "Tween"
	| Instance : node_1
	| Props : {
		["Goal"] : <prop>(layout_0,1),
		["Property"] : "Offset",
		["EasingDirection"] : "In",
		["EasingStyle"] : "Sine",
		["Time"] : 5
	}
</animation>

<timeline>
	| ID : "timeline_0"
	| Animation : tween_0
	
	| [1] -> {
		["Goal"] : <cframe>([0,10,5]),
		["EasingStyle"] : "Back",
		["EasingDirection"] : "InOut"
	}
	| [1] -> {
		["Goal"] : <cframe>([0,0,0])
	}

</timeline>

Timelines attach themselves to the animation, so it plays when the animation plays
